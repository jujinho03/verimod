## 실행 순서와 현재 위치

1. **완료:** 실제 모델 점수 → 정책 → 영수증 → 원본 SQLite 저장 → 실제 Freeze → 공개 JSON 인계.
2. **현재:** 최소 ACL·전용 F 계정·Windows OpenSSH·사설 VPN·승인 RPC 준비. UAC 접근과 승인 대기.
3. **미실행:** 인증 채널 prepare ACK → T 동일 bytes 송신 → A submitted → 12회 이상 확인 후 F confirmed.
4. **미검증:** 같은 실제 seed를 외부 브라우저에서 VALID/HASH_MISMATCH/INVALID_PROOF로 확인하고 팀 GATE 판정.

별도 노트북 간 연결에는 Tailscale 같은 사설 네트워크와 **Windows OpenSSH**를 사용합니다.
Windows에서 Tailscale 내장 SSH 서버를 사용하지 않습니다. 포트 공인 공개/DB·키 이동은 없습니다.

## 정책 승인과 신뢰 경계

정책은 `W4_PROVISIONAL_E2E_ONLY`, `team_approved=false`입니다. 정식 선택 규칙은
FRR≤X, HRR_TOTAL≤B를 만족하는 후보 중 HAR 최소, 동률이면 RP 최대→HRR_TOTAL 최소입니다.
X/B가 승인되지 않아 운영 정책을 채택하거나 LOCK하지 않았습니다. `none`은 정상 클래스의
운영 proxy로만 사용하며 플랫폼에서의 정상 판정/ALLOW와 동일하지 않습니다.

실제 Epoch의 공개 proof/anchor는 null입니다. 모델의 실제 실행과 정확성을 blockchain이
증명한다고 주장하지 않습니다. T의 공개 JSON 독립 검증 PASS는 사용자 팀 보고이며 이번
