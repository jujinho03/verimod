## 방향성 확인

마스터플랜 v1.2.1을 실행 우선 문서로 사용한다. Cross-LLM Master Prompt는 제품의 canonical handoff context로 사용하되 충돌 시 마스터플랜을 우선한다. 핵심은 AI 판정의 정답 증명이 아니라, Decision Receipt가 외부 anchor 당시의 기록과 같은지 이용자 브라우저에서 검증하는 것이다.

## CURRENT 구현 경계

- browser 기반 synthetic PoC: canonical JSON, SHA-256, Merkle proof, receipt verification, tamper state와 합성 ledger가 있다.
- `backend/contracts/ToolchainCheck.sol`은 실제 anchor contract가 아니다.
- 실제 Base Sepolia contract, 배포 tx, RPC reader, wallet/faucet 잔액은 아직 증거가 없다.
- `backend/contracts/.env.example`만 버전 관리한다. 실제 `.env`는 생성됐지만 `.gitignore`로 제외되며, private key는 출력·문서화하지 않았다.
