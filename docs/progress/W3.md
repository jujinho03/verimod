### 구현 내용

#### SQLite 7테이블

`backend/src/database.ts`가 다음 테이블을 한 migration으로 만든다.

1. `receipts`: canonical body, hash UNIQUE, issuer_seq UNIQUE, owner. 수정·삭제 route 없음.
2. `content_store`: 원문, 32-byte salt의 lowercase hex 표현, commitment UNIQUE, owner. 공개 조회와 분리.
3. `epochs`: root/count와 FROZEN~FAILED 상태, tx 운영 필드.
4. `epoch_members`: receipt_hash UNIQUE, epoch 내 leaf_index PK.
5. `appeals`: original receipt당 UNIQUE인 W3 schema placeholder.
6. `reviews`: target당 UNIQUE인 W3 schema placeholder.
7. `idempotency_records`: `(principal, operation, key)` PK와 별도 request hash, stored response.

서버 시작 때 receipt가 없는 중단된 `IN_PROGRESS` claim만 회수한다. 이 구현은 단일 Node process PoC 경계이며 다중 instance lease는 동결되지 않았다.

#### `POST /api/decisions`

- 임시 transport는 exact `{text}`와 `x-demo-principal`, `x-demo-role: DEMO_USER`를 사용한다. role 문자열은 identity proof가 아니다.
- salt는 CSPRNG 32 bytes이고 공개 표현은 `0x` 없는 lowercase hex 64자다.
- 원문은 정규화하거나 echo하지 않는다.
- A/T 실제 adapter가 없으므로 dependency injection boundary를 제공한다. 기본 adapter는 항상 safe failure다.
- 테스트 fixture만 BEEP native `hate/offensive/none`, score keys `hate/offensive`를 사용한다. deterministic fixture이지 real model output이 아니다.
- 현재 T shared runtime `ReceiptBody` validator는 legacy five-label demo라 BEEP body를 아직 승인하지 못한다. canonical/hash primitive만 재사용했고 이 mismatch는 entry freeze 의존성이다.

#### 멱등성과 실패

- request hash는 현재 exact `{text}` canonical bytes의 SHA-256이다. 최종 request-hash 범위는 팀 freeze가 필요하다.
- 동일 요청의 실행 promise를 합쳐 동시 8회도 inference 1회, receipt 1건으로 끝낸다.
- 발급 transaction은 receipt, content_store, stored response를 함께 commit한다.
- adapter/policy/hash/persistence가 성공하기 전에는 완료 응답을 저장하지 않는다.
- provider failure는 `503 INFERENCE_UNAVAILABLE`; ALLOW fallback, dummy score, dummy receipt, anchor candidate를 만들지 않는다.

#### 공개 조회와 manifest 경계

- `GET /api/receipts/:id`: body/hash와 `PENDING_ANCHOR`; 원문/salt 없음.
- `GET /api/receipts/:id/bundle`: proof/anchor가 둘 다 null인 pre-anchor bundle.
- `GET /api/manifests`: 현재 shared manifest를 `LEGACY_SYNTHETIC_DEMO`로 표시하고 BEEP target taxonomy를 `AWAITING_W3_FREEZE`로 별도 노출한다.
- 실제 외부 anchor 전까지 ANCHORED 또는 BASE_SEPOLIA_VERIFIED를 반환하지 않는다.
