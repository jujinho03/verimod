## 제출 및 개인정보 경계

- CNU MATE 제출·접수·승인은 **OPS-04 NOT_VERIFIED**입니다. 이메일 발송 기록이나 수행일지 작성만으로 플랫폼 접수를 확정하지 않습니다.
- 멘토 이메일, 원본 PDF, 연락처, 원문, salt와 개인 데이터는 공개 저장소에 추가하지 않습니다.
- 새 플랫폼 제출·수정은 별도 허가와 실제 제출 결과 확인이 필요합니다.

## 문서 읽기 기준

| 표시 | 의미 |
| --- | --- |
| 기준일·기준 SHA | 문서가 대조한 시점과 코드입니다. 최신 main이나 새 실행을 자동 보증하지 않습니다. |
| 역사 기록 | 당시 판단을 보존한 자료입니다. 이후 상태는 날짜가 있는 별도 안내와 근거를 확인합니다. |
| PASS / PARTIAL / NOT_VERIFIED | 명시된 조건과 증거 범위에 한정된 판정입니다. 검증하지 않은 결과는 PASS가 아닙니다. |
| LIVE / SYNTHETIC / RECORDED | 실제 실행, 합성 시뮬레이션, 사전 녹화의 출처를 구분합니다. |
