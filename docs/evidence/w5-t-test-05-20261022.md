## EIP-1898와 latest의 범위

`eth_call epochs(1)`을 transaction의 block hash `0xacd…a43cf`와 `requireCanonical=true`로 조회했고, 같은 값이 반환됐다. `latest` 조회도 동일했다. hash-bound 조회는 그 canonical block에서의 getter state를 묶지만, RPC 제공자가 정직하게 응답한다는 가정과 이후 전체 이력의 완전성/freshness 보장을 제거하지 않는다.

이번에는 실제 네트워크를 끊는 장애 시험을 수행하지 않았다. 따라서 이 문서는 공개 RPC의 성공 응답만 기록하며, Mock/Stub 결과를 실제 RPC 장애 재현으로 주장하지 않는다.
