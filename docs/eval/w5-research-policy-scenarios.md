이 문서의 범위는 **연구·시연(RESEARCH_DEMO) 정책 비교**다. 실제 플랫폼의 운영 승인이 아니다. X/B는 연구용 가정이고, 실제 검토 인력이나 처리 용량을 조사해 정한 값이 아니다. 예를 들어 "B=30%는 검토자가 감당할 수 있는 비율"이라고 말할 수 없다. X/B=null, team_approved=false, 새 Manifest·정책 hash 미생성, LOCK 없음, TEST SEALED 상태는 그대로다.

## 1. 공식 선정 결과

선정 규칙은 바꾸지 않았다: **FRR≤X AND HRR_TOTAL≤B → HAR 최소 → RP 최대 → HRR_TOTAL 최소**. 전체 Validation 1,255건 기준이며, 정상 proxy(none)는 547건, 유해 proxy(hate+offensive)는 708건이다.

|---|---|---:|---|---|---|---|---|
| **S1 FRR 보호 우선** | 6% / 45% | 4 | **H50-90_O50-90** | 32/547 · 5.85% | 90/708 · 12.71% | 220/252 · 87.30% | 542/1255 · 43.19% |

세 시나리오 모두 사전에 예상한 후보와 일치했다. 완전 동률 후보도 없다.

**실행 가능 후보와 순위 (HAR 오름차순):**

- S1: H50-90_O50-90 (HAR 90/708, 검토 542) → H75-90_O50-90 (93/708, 537) → H50-90_O75-90 (158/708, 417) → H75-90_O75-90 (203/708, 344). 네 후보 모두 FRR이 32/547이다. 2위와의 차이는 유해 허용 3건과 검토 5건뿐이다.
- S2: H50-75_O50-90 (90/708, 354) → H50-75_O75-90 (158/708, 229) → H75-90_O75-90 (203/708, 344).
- S3: H50-75_O75-90 1개뿐이다.

클래스×조치 교차표는 저장된 분자로부터 정확히 도출했다. 정상 RESTRICT는 FRR 분자, 유해 RESTRICT는 RP 분자, 유해 ALLOW는 HAR 분자다. 25개 후보 모두에서 합계 정합성을 검사했다.

## 2. 절충 분석

**S1 → S2 (검토 188건 감소의 대가):**
- 검토 542건이 354건으로 줄고, 그만큼 RESTRICT가 늘어난다(+188).
- 늘어난 188건 중 21건은 **정상 proxy 글의 자동 제한 증가**다(FRR 5.85% → 9.69%, 상대적으로 약 1.66배). 167건은 유해 proxy다.
- 유해글 자동 허용(HAR)은 그대로다. 즉 S2는 HAR를 지키면서 정상글 21건을 더 제한하고 검토 188건을 줄인다.
- 정상 오제재 1건을 피하려면 약 9건의 추가 검토가 필요하다는 뜻이다.

**S2 → S3 (검토 125건 감소의 대가):**
- 검토 354건이 229건으로 줄고, 줄어든 125건은 모두 ALLOW로 넘어간다.
- 그중 **유해 proxy 68건이 자동 허용**으로 바뀐다(HAR 12.71% → 22.32%). 나머지 57건은 정상 proxy다.
- FRR·RP·RESTRICT는 같다. S3는 오제재를 늘리지는 않지만, 유해글 통과를 1.76배로 늘려 검토량을 맞춘다.

**경계 여유 (Validation 기준):**

| 시나리오 | X 여유 | B 여유 | 같은 실행 가능 집합이 유지되는 구간 |
|---|---|---|---|
| S1 | 6%×547 = 32.82 → 최대 32건, 현재 32건. **여유 0건** | 45%×1255 = 564.75 → 최대 564건, 현재 542건. 여유 22건 | X∈[32/547, 53/547), B∈[544/1255, 1] |
| S2 | 10%×547 = 54.7 → 최대 54건, 현재 53건. 여유 1건 | 30% → 최대 376건, 현재 354건. 여유 22건 | X∈[53/547, 74/547), B∈[354/1255, 388/1255) |
| S3 | 여유 1건 | 20% → 최대 251건, 현재 229건. 여유 22건 | X∈[53/547, 74/547), B∈[230/1255, 273/1255) |

S1은 Validation의 FRR이 X 경계에 정확히 맞닿아 있다. 25개 후보의 최소 FRR이 32/547이기 때문이다. 정상 오제재가 1건만 늘어도 X=6%를 넘는다. 따라서 "S1은 FRR 6% 이하를 보장한다"는 주장은 Validation 밖에서는 성립하지 않는다. S2·S3도 X 여유가 1건뿐이다. 세 시나리오 모두 Validation에서 선택 결과를 재현했을 뿐, 다른 자료에서 X/B 준수를 예측한 것이 아니다.

## 3. 한계

- **Proxy:** none을 정상, hate/offensive를 유해로 본 BEEP 주석 proxy다. 실제 정책 위반 여부를 따로 판정한 것이 아니다. offensive F1이 0.542이고, AI-13의 오제재 10건 분석에서도 주석 경계가 모호한 사례가 확인됐다([오류 분석](w5-validation-error-analysis.md)).
- **Validation 한정:** 1,255건 단일 split이고, 점수는 UNCALIBRATED다. 실제 Validation에 TRUNCATED는 0건이었다. 도메인(뉴스 댓글)·시점·주제 분포가 바뀌면 FRR/HRR이 크게 움직일 수 있다. 신뢰구간도 아직 없다. bootstrap CI는 LOCK 후 TEST에서만 계산한다.
- **검토 인력 없음:** HUMAN_REVIEW 건수는 "검토로 보낸 건수"일 뿐이다. 검토자가 올바르게 판정했다는 효과는 측정하지 않았다. 실제 검토 인력·처리시간·대기열 근거도 없다. 따라서 검토/1,000건은 비용의 상대 비교에만 쓴다.
- **후보 풀 고정:** 25개 후보 밖의 threshold나 규칙(BOTH-high, none-high, calibration)은 탐색하지 않았다. 3회차 멘토의 BOTH-high 아이디어는 채택된 사양이 아니다.
- **TEST 미평가:** 어떤 시나리오도 TEST 성능을 근거로 하지 않는다. TEST는 LOCK 이후 1회만 평가한다.

## 4. A 의견 — 추천과 대안

**FRR 우선 원칙(3회차 멘토 Q1)을 그대로 적용하면 S1이 가장 일관된 선택이다.** S1은 25개 후보 중 관측 최소 FRR을 달성하면서 HAR도 최저 수준(12.71%)을 유지한다. "HUMAN_REVIEW 완충지대로 정상글 오제재를 막는다"는 발표 논리를 그대로 보여 준다. S2보다 늘어나는 188건의 검토 중 167건은 원래 자동 제한될 유해글이므로, 유해글이 통과되는 방향의 위험은 늘지 않는다.

S1의 약점은 두 가지다. 검토가 43%로 많아 자동화 범위가 약 57%에 그친다. 그리고 X=6%의 여유가 0건이다.

**S2는 정당한 대안**이다. HAR를 유지하면서 검토를 28%로 줄인다. 대신 정상 proxy 오제재 21건 증가(FRR +3.84%p)를 명시적으로 수용해야 한다. 팀이 "시연 정책이라도 검토 40% 이상은 비현실적"이라고 판단하면 S2가 합리적이다. 다만 이 경우 FRR 우선 원칙보다 검토량을 앞세운 결정임을 발표에서 밝혀야 한다.

**S3는 비추천**이다. 검토 125건을 줄이려고 유해글 자동 허용 68건을 수용한다. 이는 HAR를 1.76배로 늘리는 선택이며, 검토량이 적다는 이유만으로 안전하다고 할 수 없다.

## 5. 팀장 승인란 — RESEARCH_DEMO 범위

아래 항목은 **연구·시연 정책** 승인이다. 운영 정책 채택, Manifest 확정, LOCK, TEST 개봉, F 코드 변경, push는 포함하지 않는다. 비어 있는 항목은 미승인이다.

| 항목 | 기록 형식 | 승인 값 | 승인자·시각 |
|---|---|---|---|
| 승인 범위 | `RESEARCH_DEMO` (운영 아님) | ☐ | |
| X (FRR 상한) | 정확한 분수. 예: 6% = 3/50, 10% = 1/10 | ☐ | |
| B (HRR_TOTAL 상한) | 정확한 분수. 예: 45% = 9/20, 30% = 3/10, 20% = 1/5 | ☐ | |
| 선정 후보 | 승인된 X/B에 공식 규칙을 적용한 결과만 가능. 임의 지정 불가 | ☐ S1 H50-90_O50-90 ☐ S2 H50-75_O50-90 ☐ S3 H50-75_O75-90 | |
| 채택·기각 사유 | 정상 오제재와 검토량 절충에 대한 팀 판단 | | |
| 유지 사항 확인 | R01, 3-class, UNCALIBRATED, ANY_RESTRICT, TRUNCATED→HUMAN_REVIEW 유지 | ☐ | |
| 발표 표현 확인 | "연구·시연 정책이며 운영 인력 검증 없음"을 슬라이드에 명시 | ☐ | |

승인되면 A가 수행할 일:
1. 승인값과 승인 기록을 결합한 공식 선정 경로를 보완한다.
2. 25개 후보에 대한 선정 결과를 다시 기록한다.
3. [A/F 계약 제안](../handoffs/W5-A-F-policy-contract-proposal.md)을 F와 합의한다.

**승인만으로는 `team_approved=true` 설정이나 Manifest 확정이 이뤄지지 않는다.**
