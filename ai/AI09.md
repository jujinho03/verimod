## Request and response

`POST /infer`, `Content-Type: application/json`:

```json
{
  "text": "오늘은 날씨가 좋아서 친구와 함께 산책했어요.",
  "content_commitment": "0xabababababababababababababababababababababababababababababababab",
  "request_id": "korean_short"
}
```

The request shape is an AI-09 local transport choice because C01 did not freeze a
request schema. `text` and lowercase hex32 `content_commitment` are required;
`request_id` is optional (otherwise UUID v4), 1–128 ASCII ID characters. Extra keys,
non-string text, lone Unicode surrogates and malformed JSON are rejected. Blank or
whitespace-only text produces `EMPTY_INPUT`. Validation failures receive a generated
request ID; valid requests preserve the provided request ID.

Inference reuses `preprocess_text`, `score_array`, `score_to_ppm`, and `validate_i1`.
Processing is 500 Unicode codepoints HEAD, then pinned tokenizer right truncation
to 128 tokens including special tokens. Either truncation sets `TRUNCATED`.
Actual selected-model logits produce three native softmax scores. Only `hate` and
`offensive` are converted once each with `floor(score * 1_000_000 + 0.5)` and exposed.
There is no sum repair, renormalization of the two exposed scores, conversion of
`none` to ALLOW, or policy/action generation. Scores remain UNCALIBRATED, evidence
is empty, and the caller's original commitment is returned unchanged.

## Fail closed

Every handled `/infer` failure uses only
`{"ok":false,"request_id":"...","error":{"code":"...","retryable":false}}`.
No scores or inference object are attached to errors.

| Condition | HTTP | I1 code | Retryable |
| --- | --- | --- | --- |
| Empty/whitespace text | 400 | EMPTY_INPUT | false |
| Invalid body/Unicode/commitment | 400 | INVALID_INPUT | false |
| Nonfinite/wrong-shape logits or invalid I1 scores | 503 | INVALID_MODEL_OUTPUT | false |
| Deadline exceeded | 504 | INFERENCE_TIMEOUT | true |
| Missing/corrupt model, failed load/forward, occupied slot | 503 | INFERENCE_UNAVAILABLE | true |

503 unavailable follows D24's working assumption. Other status/retry mappings are
AI-09 local choices, **not a claim that the draft I1 transport is now frozen**.

`VERIMOD_INFERENCE_TIMEOUT_SECONDS` defaults to 10; it must be finite and positive.
`VERIMOD_MODEL_DIR` and `VERIMOD_HF_CACHE` can relocate local artifacts; the SHA and
revision pins still apply. Requests cannot override those settings.

The event loop awaits one bounded executor slot. Deadline/disconnect discards late
results, consumes late exceptions, and retains the slot until the native forward
finishes. Concurrent calls fail closed with 503; there is no unbounded queue.
A permanently hung native forward requires process restart: the timeout bounds
the HTTP wait, not the execution time of native PyTorch code. This is a local CPU
service, with no production throughput or cross-machine performance claim.
